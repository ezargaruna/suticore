una perla de SUTI.worldel cristal de claridad :: distinción · esencia · rumbo

claridad :: qué ocurre → qué importa → un próximo paso

distinción :: hecho ≠ observación ≠ interpretación ≠ hipótesis ≠ símbolo

esencia :: núcleo → conexiones → rumbo → acción

cómo trabajamos
observar → distinguir → relacionar → verificar → decidir → actuar → dejar un rastro → adaptar

ciclo del proyecto
intención → primera forma útil → comentarios → cierre → dejar un rastro

herramienta de trabajo de autoría propia; no es una prueba científica ni un diagnóstico.
