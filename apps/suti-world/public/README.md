# app prototype · static assets

This directory contains static assets used only by the Vite document browser
in `apps/suti-world/`.

The public SUTI.world homepage and installable SUTI.world web app are separate. Their
entry and deployable assets are the repository-root `index.html`,
`manifest.webmanifest`, `service-worker.js`, and `site/` directory.

GitHub Pages copies that explicit root surface; it does not publish this
prototype's assets or build the prototype.
