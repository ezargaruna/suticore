# suti development kit

version: 0.1
status: draft
category: normative specification
domain: semantic architecture

---

## purpose

SUTI Development Kit (SDK) is the canonical toolkit for creating,
verifying, building and publishing systems derived from SUTIcore.

The SDK is implementation-independent.

It defines the public development interface for semantic architectures.
