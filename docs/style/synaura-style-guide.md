# стиль synaura · руководство

статус: рабочее правило
для нового публичного текста

источник: `CODEX_TASK.md`

## область

сайт, README, документы,
шаблоны, промпты, интерфейс
и сообщения агентов

применяй к изменяемому материалу

архив не переписывай
без отдельного запроса

## регистр

по умолчанию — строчные буквы

сохраняй официальные имена,
названия брендов и фреймворков,
код, прямые цитаты
и требования языка

канонические имена:

`SUTI.world` · `SUTIcore` · `SUTIspace`

`LinguaFUSION` · `VereNITYA`

`Syntaxium` · `SRETENIYA_OS` · `AI`

не делай массовую замену регистра

проверяй контекст каждого исправления

## ритм и плотность

один смысл — один блок

предпочитай короткие строки

ориентир — до семи слов

сначала ответ, затем контекст

детали раскрывай по необходимости

не дроби связную инструкцию
до потери смысла

## символы

используй символ,
только если он несёт функцию

`∴` ядро · `⧖` пауза

`⟁` действие · `〄` интеграция

`↺` повтор или возврат

## проверка текста

кому это → зачем → контекст

риск → следующий шаг

удали повтор, канцелярит,
пустую абстракцию,
необоснованное обещание
и декор без смысла

перед commit проверь
лишние заглавные,
канонические имена,
ясность действия,
кодовые идентификаторы
и прямые цитаты

исключения запиши в отчёте
