# SUTI.world · публичный стиль

статус: правило для всех новых и изменяемых материалов
visual authority: SUTI Design System 2027

## ясный голос

показывай пользу и следующий шаг
пиши коротко, тепло и точно
раскрывай подробности по запросу
оставляй место для паузы и отказа

сложность остаётся внутри
человеку видна ясная форма

## язык и обучение

начинай с реальной ситуации
показывай понятный пример
предлагай вспомнить и попробовать
возвращай полезную форму позже
поддерживай проверку без оценки личности

возраст влияет на примеры,
темп, доступность и безопасность

человек выбирает формат сам
не выводи тип из одного ответа

## интерфейс

- заголовки: Nunito Sans Variable · текст и интерфейс: Manrope
- Turquoise `#57B8B0` — живое взаимодействие; Sunlight `#D6AD58` — редкая точка света
- темы: DAY / NIGHT / CONTRAST
- цветовые роли проходят через tokens
- движение связано с действием
- reduced motion обязателен

## доступ и условия

на странице одна главная бесплатная практика
личные услуги обозначены отдельно
срок, объём и стоимость согласуются заранее

не проси личную историю
не обещай результат без основания

## приватность и публикация

сайт не хранит пользовательский текст
он не отправляет его третьим сторонам

публикуй только проверенные открытые материалы
личные заметки и профили исключай

```text
задача → один вход → короткий маршрут
источник → права → приватность → сборка
контраст → клавиатура → узкий экран → возврат
```
