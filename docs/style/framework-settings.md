# framework settings

A public design profile for the SUTI frameworks.

These names describe an authorial system of methods and documents. They do not claim independent technologies, scientific validation, diagnosis, or guaranteed outcomes.

The profile follows this order:

```text
safety → accessibility → choice
→ clarity → context → atmosphere
→ decoration
```

## shared visual language

The SUTI.world default is warm, material, spacious, and precise. It may change by project. The Synaura interaction principles remain stable when the visual theme changes.

Use a light surface as the default. Keep color subordinate to text and structure. Status always has a written label; color never carries it alone. Check contrast in the implemented interface.

## type and space

- serif for editorial voice and reflection
- sans serif for navigation and action
- monospace for identifiers and trace data
- body text from 16 px
- line height around 1.55–1.7
- text measure around 48–68 characters
- use an 8 px spacing base with a 4 px half-step
- leave room around a decision and its next action

Use typeface choices already available in the product. Do not load an external font solely for decoration.

## rhythm and pulse

A page moves through orientation, distinction, action, and trace. Each block carries one main idea and a visible next step.

Use three reading densities:

- **quiet** — one claim or choice
- **normal** — claim with its context
- **dense** — claim, evidence, and limits

Pulse is a brief signal for a meaningful change, such as a selected state or completed step. It must not run continuously, demand attention, or imply that a claim is true. Provide an equivalent text label. Respect `prefers-reduced-motion`; reduced motion removes the pulse without removing information.

## symbols

Use a symbol only when it adds a stable structural cue. Pair unfamiliar symbols with a text label. Prefer words when they are clearer.

```text
∴ principle · ⧖ pause · ⟁ action
〄 integration · ↺ return
```

Do not place more than one decorative symbol beside a heading. Never use a symbol as evidence, diagnosis, or instruction to a person.

## interaction

- keep the next action explicit
- make pause, refusal, and exit available
- keep actions reversible where possible
- use semantic controls and keyboard focus
- support zoom to 200 percent
- provide at least 44 px touch targets
- avoid autoplay, flashing states, and endless parallax
- include a reduced-motion mode

## open claims and status

Describe each framework as an authorial method, model, or research direction. Separate fact, observation, interpretation, hypothesis, evaluation, symbolic material, and unknown. Use `UNKNOWN` or `HOLD` when evidence or authority is missing.

Do not publish personal maps, client or student material, private correspondence, credentials, local paths, private agent settings, or unpublished collaborator work in protocol examples.
