# дизайн-система SUTI.world

статус: рабочая версия

источник: бриф пользователя

## характер

тихо, ясно,
межкультурно и природно

простор и мягкие цветовые поля

бумага, воздух, вода,
лист и мягкий свет

смысл перед декором

без эзотерической графики

## цвет

`apps/suti-world/src/styles/theme.css`

## применение

бумага — основная поверхность

чернила — основной текст

лес — тёмное поле

мох — фокус и акцент

персик, небо и солнце —
три входа

граница — тихое разделение

## доступность

основной текст сохраняет контраст

у ссылок есть текстовая метка

фокус виден с клавиатуры

движение отключается,
если пользователь попросил

макет складывается
в одну колонку
на узком экране
