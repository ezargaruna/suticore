# SUTIcore

**Language and semantic architecture for clearer questions and traceable meaning.**

This repository contains public specifications, the canonical source and deployment workflow for [SUTI.world](https://suti.world/), and selected local-first tools. It defines methods and interfaces; it is not the portable personal vault. GitHub Pages assignments are separated; Cloudflare origin settings remain uninspected. See [repository contours](docs/repository-contours.v1.md).

## SUTIcore scope

SUTIcore holds the reusable language and semantic architecture: definitions, source-aware methods, review contracts, implementation notes, and the public website. Individual artifacts retain their own provenance, license, maturity, and runtime status.

The work distinguishes observation, interpretation, hypothesis, symbol, and unknown. A specification does not prove an implementation; a local tool does not imply a hosted service; publication does not certify scientific or clinical claims.

### Research collaboration

The [research collaboration brief](docs/research/SUTI_RESEARCH_COLLABORATION.md) proposes a bounded review of selected public materials. Scope, rights, data boundaries, attribution, and publication terms are agreed before any transfer; the brief does not imply an existing partnership or grant access to private archives.

Public byline: **Ezar Garuna · Saritama**. Creative names describe an authorial voice and are not credentials or official roles.

## Contours

```text
SUTIcore  → methods, specifications, SUTI.world source
SUTI.os   → portable Markdown vault, local installer, language entry packs
```

The repositories link to each other but have separate payloads and release histories. Do not copy personal vault data into SUTIcore or treat a website snapshot inside SUTI.os as the canonical site source.

## Language navigation

The site opens in Russian unless a visitor has saved another language or supplied an explicit locale. The homepage interface and its six local practice routes now have twelve written language editions: Russian, English, Spanish, Brazilian Portuguese, French, Arabic, Simplified Chinese, Hindi, Bengali, Esperanto, Sanskrit and Latin. Yazekh remains an authorial route with an explicit Russian semantic gloss. The atlas, text studio, world workshop and care/veche wrapper expose thirteen corresponding routes. These are editorial drafts: independent native/expert review is pending, and linked historical documents keep their own source-language and review states. This does not establish complete transcreation of the entire legacy site or source vault. See [homepage coverage](locales/homepage/coverage.json), [atlas coverage](locales/world-atlas/coverage.json) and the [language matrix](docs/language-layers.md).
