## ориентиры

- ясность важнее декоративной сложности
- карта не заменяет человека
- символ не служит доказательством
- автоматизация предлагает, человек решает
- пауза, отказ и возврат всегда доступны
- неизвестное остаётся неизвестным, пока не проверено
