# ∴ s u t i c o r e

SUTIcore is the conceptual and semantic kernel of the SUTI ecosystem.

It develops the foundational architecture for recursive distinction, semantic structures, conceptual engineering and epistemic governance.

The repository contains research, standards, reference models and experimental implementations that support the evolution of the core architecture.

SUTIcore is developed as an open engineering research program.

---

# ∴ s u t i . w o r l d

SUTI.world is the public research platform built upon SUTIcore.

It serves as the interface through which semantic architectures, standards, educational resources, collaborative research and practical implementations become accessible.

Where SUTIcore develops the architecture, SUTI.world cultivates its ecosystem.
