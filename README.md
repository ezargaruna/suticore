## ⟁ каноническая спецификация

SUTIcore определяет каноническую модель ограничений для семантических архитектур
спецификация задает минимальные нормативные концепты, принципы и инварианты
необходимы для построения и оценки архитектур независимо от реализации

### нормативные принципы
семантические архитектуры управляются явными ограничениями
ограничения определяют допустимое пространство трансформаций
протоколы управляют допустимыми операциями
валидность архитектуры сохраняется только через допустимые трансформации

---

## ⟐ канонический словарь

### constraint (ограничение)
фундаментальный семантический примитив
определяет допустимое пространство трансформаций
управляет валидностью архитектуры

### protocol (протокол)
область трансформации под управлением ограничений
определяет допустимые операции внутри архитектуры

### node (узел)
стабилизированная семантическая конфигурация
создана под действием одного или нескольких пространств ограничений
обеспечивает стабильные точки отсчета для отношений

### operation (операция)
трансформация, оцениваемая под явными ограничениями
только допустимые операции сохраняют валидность

### projection (проекция)
представление семантической структуры в другой среде
архитектура :: документация
модель :: реализация
граф :: база данных
спецификация :: рантайм

## ⚙ нормативные инварианты

явные ограничения :: операции оцениваются только под явно объявленными ограничениями
архитектурная валидность :: любая допустимая трансформация сохраняет управляющие ограничения
отсутствие избыточности :: новая абстракция вводится только при невозможности выразить различие
рекурсивная композиция :: любой узел может быть частью архитектуры высшего порядка
