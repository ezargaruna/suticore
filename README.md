## ∴ Overview

SUTIcore is the kernel of the SUTI ecosystem.

It is an open semantic operating system for designing languages, cognitive architectures, symbolic protocols, and environments where meaning becomes executable.

Rather than describing reality, SUTI explores how reality is structured through language, attention, and recursive organization.
