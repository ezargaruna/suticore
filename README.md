## ⟁ структура системы

### 00_KERNEL (ядро)
фундаментальные аксиомы, канон и синтаксиум 2027.
точка сборки всех определений и правил системы.

### 01_MEMORY (память)
библиотеки смыслов и лингвистические карты.
инструменты для работы с языком и памятью (SUTI-pure).

### 02_PROJECTS (проекты)
активные воплощения системы в реальности.
SUTIcore :: Yazekh :: Verenitya.

### 03_FLOW (потоки)
логи действий, журналы решений и трассировка следов.
динамика перехода от вопроса к результату.

### 04_AI (интеллект)
протоколы взаимодействия с LLM.
правила фильтрации шума и извлечения сущностей.

## 〄 инструменты и технологии

- la-app (SUTI-world) :: интерфейс доступа к знаниям.
- go-tools :: инструменты верификации и построения графов.
- obsidian :: локальный контур работы с заметками.
- ollama :: локальный интеллект для обеспечения приватности.
