## what it does

## binary filter

every entry passes through a single binary filter:

```
input:   ≤7 words · verb + object · no roles
verdict: 1 (action present) or 0 (noise)
```

**blacklist (auto-reject):**
```
ru: помогаю · развиваю · сопровождаю · улучшаю · консультирую
    оптимизирую · повышаю · работаю с
es: ayudo · desarrollo · acompaño · mejoro · consulto
    optimizo · impulso · trabajo con
en: i help · i develop · i support · i improve · i consult
```

**examples:**
```
"строю отдел продаж для IT"     → 1 ✔
"настраиваю рекламу для ecom"   → 1 ✔
"помогаю бизнесу расти"         → 0 ∅
"развиваю личный бренд"         → 0 ∅
```

---

## three scalpels

after filter ✔ and payment:

```
q1: что не твоё?
    what is not yours?

q2: где врёшь себе?
    where do you lie to yourself?

q3: что уже знаешь делать?
    what do you already know how to do?
```

**pause (∅) between each question.**
silence is not empty. it is where the work happens.
