# дивы семи светил :: divas 7 lights

модуль настройки спектра внимания и эмоциональных состояний. система позволяет различать семь базовых «световых» режимов работы психики и переключаться между ними для достижения конкретных целей.

## суть метода

внимание не однородно. оно имеет разную «частоту» и «цвет». дивы — это семь архетипических состояний внимания, которые позволяют оператору переключаться из режима анализа в режим творчества, из режима борьбы в режим принятия.

## спектр состояний (7 светил)

1. **свет ясности (analysis)** : холодный, сфокусированный луч. для разбора сложных структур, поиска ошибок, логики.
2. **свет тепла (empathy)** : мягкое, обволакивающее свечение. для работы с людьми, понимания чувств, поддержки.
3. **свет воли (drive)** : интенсивный, пробивной поток. для рывка, завершения задач, преодоления сопротивления.
4. **свет тишины (presence)** : ровный, глубокий фон. для медитации, слушания, наблюдения без оценки.
5. **свет игры (creation)** : мерцающий, многогранный свет. для генерации идей, импровизации, юмора.
6. **свет истины (insight)** : вспышка, прозрение. для моментального различения сути, синтеза противоречий.
7. **свет единства (synthesis)** : всеохватывающий свет. для видения всей системы целиком, стратегического планирования.

## протокол переключения

для управления своим состоянием используйте технику «смены фильтра» :

1. **осознание** : какой свет сейчас доминирует? (например, я в «свете воли», но пытаюсь проявить «свет тепла» $\rightarrow$ возникает конфликт).
2. **выбор** : какой свет нужен для текущей задачи? (задача — анализ кода $\rightarrow$ нужен «свет ясности»).
3. **настройка** : через дыхание и фокус внимания переключите состояние на выбранный спектр.

## связь с SUTI.os

модуль интегрируется через `SUTI_HOUSES_SYSTEM` :
- обитель 5 (проявление) : использование «света игры» для творчества.
- обитель 6 (порядок) : использование «света ясности» для дисциплины.
- обитель 12 (тишина) : переход в «свет тишины» для восстановления.

*внимание — это инструмент. управляйте его цветом.*
