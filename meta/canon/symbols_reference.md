# symbols for clear reading

symbols are optional visual cues.
their meaning stays available in words.

use a mark when it helps navigation.
leave it out when it adds noise.

## core palette

| mark | function | plain-language label |
|---|---|---|
| `∴` | core or main point | the essential point |
| `◎` | focus | what matters now |
| `⌖` | context or node | where this applies |
| `◇` | distinction or option | what differs or is possible |
| `↔` | relation or exchange | how these parts relate |
| `→` | sequence or transition | what follows |
| `≠` | keep concepts separate | these are not the same |
| `⊣` | boundary or excluded scope | what stays outside |
| `⧖` | pause or transition | take time before continuing |
| `◌` | optional space | skip or leave room |
| `⟁` | chosen action | one step to try |
| `✦` | useful finding | a point to keep |
| `↺` | return or review | revisit and revise |
| `〄` | integration | bring selected parts together |
| `∅` | intentional omission | not included in this pass |

## extended palette

| mark | function | plain-language label |
|---|---|---|
| `≋` | repeated, user-confirmed signal | a pattern noticed again |
| `≈` | approximation or working version | provisional, open to change |
| `⟡` | possibility or emerging idea | a possibility to explore |
| `◉` | overview or map | the whole view |
| `△` | open question in a diagram | a point still to examine |
| `☼` | light-theme control | day display |
| `◐` | dark-theme control | night display |
| `◩` | contrast-theme control | high contrast |
| `＋` / `−` | disclosure control | expand / collapse |
| `A+` / `A−` | text-size control | larger / smaller text |

## use and access

- pair an unfamiliar mark with a visible text label.
- keep labels available to assistive technology.
- never use color or shape as the only status cue.
- write `UNKNOWN`, `HOLD`, or `PASS` as text when needed.
- `≋` records a repeated observation, not proof.
- a diagram mark does not assert causation or truth.
- interface controls describe their control, not a belief.
- no symbol grants access, consent, or authority.

## short note

```text
⌖ context
◎ what matters
◇ what differs
∴ current understanding
⟁ one possible step
↺ when to review
```

the note remains readable without its marks.
choose, rename, or remove any mark.
