# безопасное изменение

Используй этот порядок, когда меняешь общую структуру или настройки.

**наблюдение → план → копия → изменение → проверка → возврат**

- сначала запиши, что меняется и зачем
- сохрани исходное состояние
- меняй только выбранный объект
- проверь результат по исходной задаче
- при ошибке верни прежнее состояние

Не включай автоматическую публикацию, отправку данных, установку программ или удаление файлов по умолчанию. Такие действия требуют отдельного решения человека.
