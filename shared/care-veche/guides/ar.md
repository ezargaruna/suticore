# مساحة مشتركة للرعاية والتشاور

سؤال واضح · أصوات يمكن تمييزها · خطوة في حدود الاستطاعة · أثر محفوظ

مواصفة مشروع ونموذج أولي محلي مرشح؛ الوكلاء المتصلون بالشبكة وإرسال الرسائل والتعاملات المالية والتنظيم القانوني والنشر معطلة

أساس مشترك منزوع الهوية للأنظمة الفردية والجماعية؛ ورشة نقاش محلية

ربط المعرفة ووكالة الرعاية المقترحة والنظر المشترك، بحيث يستطيع الشخص تهيئة النظام بنفسه والتحقق من الخطوة التالية

قراءة المنهج، وتسجيل مساهمة أو موقف، ورؤية الفروق، وحفظ حزمة نقاش قابلة للنقل

تُحفظ المناهج المفيدة والإصدارات والمواد غير المحسومة؛ لا تُتلف الأصول، وعمليات النقل المختارة قابلة للعكس ولها source → target وSHA وإيصال

تحتوي الطبقة المشتركة على مناهج وأدوار وقوالب فارغة؛ تبقى القصص الشخصية وبيانات الاتصال والمراسلات والمعلومات الحساسة في النطاق الخاص المختار

ملاك الرعاية صورة اختيارية للواجهة؛ تتاح للأشخاص والوكلاء صياغة عادية للدور دون إسناد هوية أو تجارب داخلية إليهم

نوع المشارك واسمه في هذه الورشة المحلية يصرح بهما كاتب السجل؛ لم تُتحقق هنا هويات المشاركين الآخرين أو صلاحياتهم أو موافقتهم

سجلات الورشة في ذاكرة الصفحة؛ احفظ JSON قبل الإغلاق. يضيف الاستيراد السجلات التي اجتازت الفحص، ولا يستبدل التاريخ الأصلي

## الاكتمال والحفظ

احفظ الأصل وسياقه أولًا، ثم استخلص التمييز القابل للنقل. لا تصبح الملفات المتشابهة مرجعًا معتمدًا واحدًا تلقائيًا. تبقى المواد غير المحسومة متاحة مع وسم واضح؛ وتُحفظ أرشيفات العمل خارج التجميع المشترك المنقح

## نواة مشتركة منزوعة الهوية

يصف كل منهج الهدف والثابت والمدخل والإجراء والنتيجة والمصدر والحقوق والإصدار والحدود. لا يحتاج عمل المنهج إلى اسم شخصي أو قصة شخصية. يحفظ نزع الهوية التمييز المفيد، دون تقديم حالة خاصة بوصفها قانونًا عامًا

## تهيئة فردية وجماعية

يُضاف الملف الشخصي واللغة المختارة والإيقاع وإعدادات الإتاحة كل على حدة. تحدد المجموعة أدوارها ونطاق الرؤية واتخاذ القرارات. يمكن تحرير الإعدادات وتصديرها؛ ولا تُستنتج هوية الآخرين أو موافقتهم أو مشاركتهم من القالب

## وكالة الرعاية المقترحة

يبدأ الدخول بالسؤال المختار. حدد إجراءً في حدود الاستطاعة والمورد اللازم والشخص الذي يتخذ القرار. لا يقرر البوت المساعدة أو المنح أو المدفوعات أو التمثيل. يمكن توضيح الطلب أو إحالته إلى شخص مناسب أو إنهاؤه

## الرعاية في عمل الوكلاء

يتلقى الوكيل مهمة واضحة ومصادر مسموحًا بها وحدودًا للبيانات وميزانية متاحة. يسجل عدم اليقين والإخفاق المتكرر والتوقف المؤقت وتسليم العمل. هذا تنظيم تشغيلي للعملية؛ ولا تُنسب إلى الوكيل مشاعر أو معاناة أو وعي أو احتياجات بشرية

## مكان للتواصل

يمكن للأشخاص والوكلاء إعداد مساهمة واضحة المنشأ. الرسالة بيانات للنظر فيها، وليست أمرًا بالتنفيذ. لا تُدرج في الحزمة المشتركة الاستدلالات الخفية أو الأسرار أو المراسلات الخاصة الخام أو السجلات الشخصية غير المطلوبة

## مسار مجلس التشاور

يرتبط كل مقترح بسؤال وسياق وطريقة للتحقق. يُحفظ التأييد والاعتراض والامتناع وغياب الرد كل على حدة. لا يُعد الصمت موافقة. منظور AI ليس صوتًا بشريًا؛ وللخلاصة شخص مسؤول، وتبقى مسودة إلى أن يتخذ قراره المنفصل

## التحقق من الأسس

نوع الادعاء والمصدر والتحقق والقرار حقول مختلفة. تتعلق PASS بمعيار وبيئة واضحين. تبقى UNKNOWN عند نقص البيانات؛ ولا ترفع الصياغة الجميلة درجة اليقين. لا تساوي COMMIT النشر، ولا تساوي المواصفة خدمة عاملة

## حدود المشاركة

الصورة المجازية واللعب والمشاركة اختيارية. تتاح اللغة العادية والتصحيح والتوقف المؤقت والخروج. لا تحل المسارات العمرية محل التصنيف الرسمي؛ استقبال الشباب معطل إلى حين وضع شروط منفصلة، والتجربة الأولى للبالغين الموافقين. لا يُدعى هنا تقديم مساعدة طارئة أو سريرية

## ربط الوكلاء العاملين

ينقل المحول المقترح فقط المساهمة والدور والمصدر والإصدار ونطاق الإذن المختارة. لا يؤكد الاستيراد المؤلف أو الحقوق أو الموافقة. يتطلب النقل الشبكي والأسرار والأذونات والمشغل والسجل تنفيذًا وتحققًا منفصلين؛ وهي معطلة حاليًا

## اللغات ونقل المعنى

يرتبط كل إصدار بالمصدر الروسي وبصمة SHA الخاصة به. تُحفظ الأسماء وID وenums والشيفرة. تُفحص صيغ النفي وعدم اليقين والاختيار والعواقب. تُمنح язэхъ حالة تجريبية مستقلة؛ ولا تُملأ معانيها المجهولة بالتخمين

## نتيجة متاحة

اختر نطاق العمل والسؤال؛ أضف مساهمة أو مقترحًا أو موقفًا؛ تحقق من المصدر؛ احفظ JSON؛ واستورد السجلات المختارة عند الحاجة إلى ورشة محلية أخرى. لا يصبح تصديرك مشتركًا أو عامًا تلقائيًا

## الدور

### المبادر

يصوغ السؤال والسياق ومعيار الفائدة

ID :: initiator

### المشارك

يضيف أساسًا أو خيارًا أو مثالًا أو قيدًا

ID :: contributor

### المراجع

يقارن المصادر والعواقب وما فُقد من المعنى

ID :: reviewer

### الشخص المسؤول

يتخذ قرارًا منفصلًا ضمن نطاق صلاحياته المتحقق منه؛ لا يمنح وسم الدور المحلي صلاحيات

ID :: human_steward

## ID المقترح

### السؤال

ما المهم فهمه أو التعبير عنه أو التحقق منه؟

### السياق

ما الذي اختير للنظر المشترك، وعلى أي أساس؟

### المقترح

ما الخطوة المقترحة ضمن الاستطاعة، وكيف تُلاحظ النتيجة؟

### تمييز المواقف

ما الذي أُيد أو اعتُرض عليه أو أُجل أو بقي دون رد؟

### التحقق

هل حُفظت الأسس والحدود وحرية الاختيار؟

### مسودة الخلاصة

ما الذي يبقى في حالة HOLD، وما القرار الذي يجب أن يتخذه الشخص؟

### الأثر والعودة

احفظ المختار، وتحقق من النتيجة، وصحح أو أنهِ

## الموقف

### تأييد

تأييد المقترح المحدد ضمن النطاق المذكور

ID :: support

### اعتراض

قيد أو خطر محدد أو تفسير بديل

ID :: objection

### امتناع

لم يُتخذ موقف بعد؛ وقد يبقى السبب غير معروف

ID :: abstain

### لا رد

لم يصل رد؛ وهذا ليس موافقة ولا امتناعًا

ID :: no_response
