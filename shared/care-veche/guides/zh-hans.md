# 关怀与共同议事空间

清晰的问题 · 可区分的声音 · 力所能及的一步 · 留存的记录

设计规范与本地原型候选；联网智能体、消息发送、资金操作、法律组织和公开发布均已关闭

供个人和集体系统使用的去个人化共同基础；本地讨论工作坊

将知识、拟议的关怀机构与共同审议连接起来，让人能够自行配置系统，并检验下一步

阅读方法，记录贡献或立场，看清差异，并保存可迁移的讨论包

保留有用的方法、版本和未解决材料；不销毁原件，选定的迁移可撤回，并附有 source → target、SHA 和凭据

共同层只含方法、角色和空白模板；个人经历、联系方式、通信和敏感信息留在所选的私密域

关怀天使是一种自愿采用的界面意象；人和智能体都可使用普通的角色表述，不据此赋予身份或内在体验

本地工作坊中的参与者类型和姓名由记录作者自行声明；此处未核实其他参与者的身份、权限或同意

工作坊记录保存在页面内存中；关闭前请保存 JSON。导入会添加通过检查的记录，不会替换原有历史

## 完整性与保留

先保存原件及其语境，再提取可迁移的区别。相似文件不会自动合并为唯一正典。未解决材料保留可访问状态并有清晰标记；工作档案存放在整理后的共同构建之外

## 去个人化的共同核心

每种方法说明目标、不变量、输入、行动、结果、来源、权利、版本和边界。方法的使用不需要个人姓名或经历。去个人化保留有用的区别，但不把个别情形说成普遍规律

## 个人与集体配置

个人档案、所选语言、节奏和无障碍设置分别接入。集体自行规定角色、可见范围和决策范围。设置可编辑、可导出；不能从模板推断他人的身份、同意或参与

## 关怀机构（方案）

从所选问题开始。确定力所能及的行动、所需资源和决策人。援助、资助、付款及代表权不由机器人指定。请求可以澄清、转交合适的人，或结束

## 智能体工作中的关怀

为智能体提供明确任务、获准使用的来源、数据边界和可用预算。记录不确定性、重复故障、暂停和工作交接。这是流程的运行组织；不赋予智能体感情、痛苦、意识或人的需求

## 交流场所

人和智能体可以准备来源明确的贡献。消息是供审议的数据，并非执行命令。共同讨论包不包含隐藏推理、秘密、未经整理的私人通信或未经请求的个人记录

## 共同议事流程

每项提案均有问题、语境和检查方式。支持、异议、弃权及未回应分别保存。沉默不视为同意。AI 的视角不是人的投票；结果须有负责的人，在其另行决定前仍为草稿

## 依据检查

陈述类型、来源、检查和决定是不同字段。PASS 针对明确的标准和环境。数据不足时保留 UNKNOWN；优美的表达不会提高确定性。COMMIT 不等于公开发布，规范不等于运行中的服务

## 参与边界

意象、游戏和参与均出于自愿。可使用普通语言，也可更正、暂停和退出。年龄路径不能替代正式分级；在另行明确条件前，青少年接入关闭，首次试点面向已同意的成年人。此处不声称提供急救或临床援助

## 接入运行中的智能体

设计中的适配器仅传递所选贡献、角色、来源、版本和许可范围。导入不能核实作者、权利或同意。网络传输、秘密、权限、操作人员和日志需要另行实施与检查；目前均已关闭

## 语言与语义迁移

每种语言版本均关联俄语来源及其 SHA。名称、ID、enums 和代码保持不变。检查否定、不确定性、选择和后果。язэхъ 单独标记为实验；不以猜测补全未知含义

## 可取得的结果

选择工作域和问题；添加贡献、提案或立场；检查来源；保存 JSON；如有需要，将所选记录导入另一个本地工作坊。自己的导出内容不会自动成为共同或公开资料

## 提案 ID

### 问题

需要理解、表达或检验的重要内容是什么？

### 语境

选取了哪些内容供共同审议，依据是什么？

### 提案

建议采取哪一步力所能及的行动，如何观察结果？

### 区分立场

哪些内容得到支持、受到质疑、被暂缓，或未获回应？

### 检查

依据、边界和选择权是否保留？

### 结果草稿

哪些内容仍为 HOLD，需要由人作出什么决定？

### 记录与回访

保存所选内容，检查结果，更正或结束

## 立场

### 支持

在说明的范围内支持所指提案

ID :: support

### 异议

具体的限制、风险或另一种解释

ID :: objection

### 弃权

暂不采取立场；原因可以保持未知

ID :: abstain

### 未回应

未收到回应；这既不是同意，也不是弃权

ID :: no_response
