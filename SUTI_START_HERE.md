# начать с одного вопроса

Не нужно изучать всю систему. Выбери то, что сейчас поможет.

- [понять ситуацию](open/первый-маршрут.md)
- [проверить предположение](meta/frameworks/GUIDE.md)
- [сохранить ясный результат](open/алгоритмы/кристаллизация.md)
- [попробовать открытую игру](https://github.com/ezargaruna/suticore/tree/samurai-dharma/open-field)

## короткий цикл

заметь → различи → проверь → выбери → попробуй → вернись к опыту

Можно остановиться на любом шаге. Ничего не нужно публиковать или сохранять автоматически.
