# ∴ suti-presets
# готовые конфигурации для погружения в suti.os

## ⧖ установка через терминал

для быстрой установки базового набора настроек используйте команду:
`curl -sSL https://raw.githubusercontent.com/ezargaruna/suticore/main/presets/bash/install_suti.sh | bash`

---

## ⟁ доступные пресеты

### 01. planetary_rhythm (динамика)
синхронизация интерфейса с днями недели (луна, марс и т.д.)
- bash :: автоматизация смены тем
- obsidian :: динамический css-сниппет
- kitty :: смена цветовых профилей

### 02. quiet_luxury (минимализм)
максимальная очистка интерфейса от визуального шума
- цвета :: petrol and gold
- шрифты :: ibm plex mono, literata
- стиль :: lowercase, no-dots

### 03. semantic_flow (аналитика)
оптимизация под глубокую работу с данными и семантическим поиском
- инструменты :: ripgrep, fd, curlie
- obsidian :: структура для быстрых связей (zettelkasten-SUTI)
