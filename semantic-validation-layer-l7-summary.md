## Extracted Knowledge

The source describes SUTIcore as a reasoning engine for semantic validation. Its function is to prevent:

- terminological drift;
- semantic noise;
- inconsistency across interfaces.

The basic algorithm is:

1. Text input.
2. Term validation.
3. Blacklist scan.
4. Semantic structure check.
5. Friction score.
6. Deploy, revise, or reject.

The note reuses the diamond method:

- fact: what is fixed;
- process: how meaning develops;
- intent: what the meaning is moving toward.

The friction score is operational:

- `0-2`: deploy;
- `3-4`: revise;
- `5+`: reject.

The source also links SUTIcore with LinguaFUSION as a semantic adaptation protocol: concept, intent, language form, interface deployment.

The "whale algorithms" are named as roles:

- sperm whale: invariant search;
- beluga: group synchronization;
- humpback: processual development of meaning.

The final section introduces Logosphere as a semantic graph where every node is an atom of knowledge. It gives node ids, layers from void to meta, and relation types: defines, expands, contradicts, supports, implements.
