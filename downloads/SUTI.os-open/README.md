# ∴ SUTI.os · открытый контур

небольшая переносимая библиотека для ясности, языка и практики. открой папку `vault` как хранилище Obsidian или читай Markdown в любом редакторе

## начать

1. открой `vault/открытое/00 начало.md`
2. выбери один вопрос и одну практику
3. для своих записей используй пустые шаблоны в `vault/личное/шаблоны/`
4. в настройках Obsidian включи сниппет `suti-open`, если хочется оформления

игра «самураи дхармы» — добровольная авторская практика, не реконструкция традиции, диагноз или терапия. её карточки связаны между собой: путь, обители, дары, хранители, семь светил, колозар и телесная практика. все образы можно заменить обычными словами или пропустить

## установка

распакуй архив и выполни `python3 install.py`. по умолчанию скрипт установит хранилище в `~/Documents/SUTI.os-open`. можно передать другой путь: `python3 install.py /путь/к/папке`

скрипт сверяет SHA-256 файлов и останавливается, если целевая папка уже существует. он не обращается к сети, не требует системных прав и не удаляет файлы

шрифты Nunito Sans и Manrope поставляются локально под лицензией OFL. моноширинный шрифт используется только для кода

## данные и границы

открытые упражнения не отправляют ответы на сервер. личные записи остаются в выбранном тобой хранилище. не записывай личные сведения других людей без согласия
