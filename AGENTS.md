# SUTI.world · правила работы

единственный visual authority — **SUTI Design System 2027**

- один ясный человеческий вход
- сложность внутри, ясность снаружи
- язык задач вместо названий методов
- Nunito Sans для заголовков · Manrope для текста и интерфейса
- Turquoise `#57B8B0` как живой интерактивный акцент · Sunlight `#D6AD58` как редкий ориентир
- DAY / NIGHT / CONTRAST через semantic tokens
- эффекты мягкие, функциональные и отключаемые

читай `docs/style/SUTI_PUBLIC_STYLE.md`
и `docs/style/suti-world-design-system.md`
перед изменением публичного интерфейса

сохраняй происхождение, права
и приватную границу материала

не переписывай архив
без отдельного запроса

перед публикацией проверь:

1. один ясный следующий шаг
2. узкий экран и клавиатуру
3. контраст и reduced motion
4. отсутствие личных данных в сборке
5. открытые права и источники

`CANON ≠ RUNTIME ≠ PUBLIC`

публикуй только подготовленную открытую производную
